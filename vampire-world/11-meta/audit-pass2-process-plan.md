# Second-Pass Audit Process Plan

## Overview

This audit builds on the previous cycle's implementation. Now that foundational issues are fixed (budgets reconciled, knowledge timelines corrected, characters split), this pass focuses on:
1. Verifying implementation consistency
2. Finding issues created by new additions
3. Deeper analysis now that basics are solid
4. Cross-referencing between new and existing content

---

## Audit Focus Areas

### 1. Implementation Verification Audit
**File**: `audit-pass2-01-verification.md`

**Purpose**: Confirm previous fixes are internally consistent and properly integrated.

**Check**:
- Do new budget numbers match across all references?
- Do new timeline entries align with existing dates?
- Do character splits (Helena/Maren) work in all contexts?
- Are river tolls, pass economics consistent with faction budgets?
- Do propaganda campaigns match communication system constraints?

---

### 2. Cross-Reference Consistency Audit
**File**: `audit-pass2-02-crossref.md`

**Purpose**: Ensure new content properly references and integrates with existing content.

**Check**:
- Does Lysander Vex fit into Maritime Republic's political structure?
- Do border cultures reference the correct factions and locations?
- Does knowledge matrix align with faction capabilities?
- Are new economic pressures reflected in faction motivations?
- Do character speech patterns match their documented backgrounds?

---

### 3. Numeric Consistency Audit
**File**: `audit-pass2-03-numbers.md`

**Purpose**: Verify all numbers work together mathematically.

**Check**:
- Population vs agricultural capacity vs military size
- Trade volumes vs toll revenues vs faction budgets
- Secret society budgets vs documented operations
- Timeline dates and durations
- Travel times vs information lag times

---

### 4. Narrative Coherence Audit
**File**: `audit-pass2-04-narrative.md`

**Purpose**: Ensure story threads work together without contradiction.

**Check**:
- Can protagonist's journey actually work given constraints?
- Do faction responses to protagonist make sense?
- Are information asymmetries consistent?
- Do cultural collisions create intended conflicts?
- Does Silverwood's mystery have enough support?

---

### 5. Missing Detail Audit
**File**: `audit-pass2-05-gaps.md`

**Purpose**: Find remaining gaps that need filling.

**Check**:
- Which factions lack complete economic profiles?
- Which characters need more development?
- Which geographic regions are underdescribed?
- Which timeline periods have gaps?
- Which cultural interactions are still abstract?

---

## Audit Execution Process

### Step 1: File Inventory Update
Create complete list of all files including new additions from implementation.

### Step 2: Systematic Review
For each audit dimension, review:
- All files modified in implementation
- All files that should reference modified content
- All files in related directories

### Step 3: Issue Documentation
For each finding:
- **Location**: Specific file and line
- **Type**: Inconsistency, gap, or opportunity
- **Severity**: Critical, high, medium, low
- **Suggested fix**: Brief recommendation

### Step 4: Prioritization
Rank findings by:
- Impact on believability
- Cascading effects
- Implementation complexity
