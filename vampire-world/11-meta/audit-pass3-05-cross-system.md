# Third-Pass Audit: Cross-System Integration

## Overview
Verifies economics, politics, information, and narrative work together.

---

## Well-Integrated Systems

### Economic Pressure → Northern Expansion ✓
- 600k/year grain dependency drives invasion timing
- Must attack during Valdrian succession weakness
- Economic reality determines military timing precisely

### Information Lag → Tactical Advantage ✓
- Seven's 1-2 week head start matches messenger speeds
- By Week 3 regional forces converge; by Week 5+ continental hunt
- Information flow determines when pressure activates

### Faction Budgets → Operational Capacity ✓
- Order: 950k supports 15k knights + fortresses (900k) ✓
- Inheritors: 475k covers operations ✓
- Veil Keepers: 330k for cells + operations ✓
- **But see critical failures below**

### Geography → Trade → Political Leverage ✓
- Northern lacks farmland → must import → Valdris controls river
- 200k toll revenue → 600k import cost = 3:1 leverage
- Geography determines economic dependencies which create power

### Character Fatal Flaws → Plot Consequences ✓
- Each flaw drives decisions that produce systemic pressure
- Individual arcs create faction-level effects

### Succession → War Window ✓
- Four candidates, civil war possible
- North Pass only open Month 5-9
- Political calendar creates military deadline

### Knowledge Gaps → Misaligned Responses ✓
- Valdrian misreads Northern as ambition vs desperation
- All "rational" decisions lead to collective disaster

## Integration Failures

### CRITICAL: Order of Dawn Pursuit vs Budget

**Systems**: Economic + Military + Hunt Timeline

**Issue**:
- Peacetime: 15k knights × 50 = 750k + 150k fortresses = 900k (fills budget)
- Active campaign: 15k knights × 150 = 2,250,000
- **Deficit: 1,300,000 crowns**

**Claims**: "Mobilizing across continent" hunting Seven

**Reality**: Budget cannot sustain claimed pursuit intensity

**Severity**: HIGH

**Fix Options**:
1. Increase hidden funding (noble houses)
2. Reduce search intensity (some regions, not all)
3. Specify which fortresses emptied (creates vulnerability)
4. Acknowledge constraint as dramatic element

---

### CRITICAL: Maritime Coup Contradiction

**Systems**: Politics + Information + Economics

**Issue**: "Coup has damaged information reliability" BUT trade/banking operates at full capacity

**Problem**: Same courier systems carry both—can't be reliable for trade but unreliable for intelligence

**Severity**: MEDIUM

**Fix Options**:
1. Specify recovery timeline (Year 1199 disrupted, now recovered)
2. Show trade IS affected (delays, costs, losses)
3. Explain asymmetry (political network targeted, financial survived)

---

### MEDIUM-HIGH: Veil Keeper Operations vs Budget

**Issue**:
- Budget: 330k, available for ops: 165k
- Realistic ops cost: 250k+ (agents, assassinations, suppression)
- **Deficit: 85,000 crowns**

**Severity**: MEDIUM-HIGH

**Fix Options**:
1. Increase budget (government funding)
2. Reduce operations (selective, not continental)
3. Use volunteers (religious commitment)

---

### MEDIUM: Sanctified Persecution Economics

**Issue**: Persecution "destroying economic base" and "agricultural disruption growing" BUT Sanctified remains "largest grain producer" with "leverage"

**Problem**: Can't have both without consequence

**Impact**: False urgency for Northern invasion if Sanctified surplus could replace Valdris imports

**Severity**: MEDIUM

**Fix Options**:
1. Show agricultural decline explicitly (15-20% drop)
2. Show Northern considers Sanctified source
3. Remove contradiction

---

### MEDIUM: Silverwood Response Undefined

**Issue**: How does Silverwood learn and respond to Seven's awakening?
- Instant magical sensing? They act first
- Through Thandril? Takes weeks
- Don't respond? 1000-year prep meaningless

**Severity**: MEDIUM

**Fix Options**:
1. Decide one mechanism immediately
2. Make it costly (ritual, drain)
3. Make it plot point (someone must discover how)
4. Make it character-driven (only Thandril can trigger)

---

### LOW: Travel Time Precision

**Issue**: Order "dispatches" hunting parties Week 1, but deployment takes 6+ additional days

**Severity**: LOW

**Fix**: Clarify "dispatch" means departure, arrival is Week 2-3

## Verdict

**Core Systems Work**: Economic pressure drives politics, information creates asymmetries, geography determines trade, character flaws create consequences.

**Broken Connections**: Three factions have budget/capacity mismatches. One faction's mechanism undefined.

**Assessment**: Worldbuilding MOSTLY WORKS. Failures are unresolved implementation details, not fundamental breaks. Need decision-making before writing scenes that depend on them.
